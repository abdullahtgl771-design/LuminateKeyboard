# Luminate Keyboard

Android keyboard project built with Kotlin. The complete source archive is `LuminateKeyboard-source.zip` in this repository.

- Package: `com.luminate.keyboard`
- App label: `Luminate Keyboard`
- Version: `1.1` (versionCode 2)
- Compile SDK: 34; min SDK: 24
- Build: JDK 17 + Gradle 8.7; run `gradle assembleDebug`

GitHub Actions is configured to build a debug APK on pushes and manual dispatches.
